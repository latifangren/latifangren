## 🧭 About Me

I'm Latifan, a builder from **Kebumen, Indonesia**.

I like building practical systems around **Android networking**, **proxy infrastructure**, **automation workflows**, and **operator dashboards**.
Most of my work comes from real experiments: breaking things, testing them, documenting what survives, and slowly turning messy ideas into usable tools.

My current focus is improving:

* cleaner software architecture
* better README and documentation quality
* reproducible setup flows
* testing habits
* deployment and troubleshooting workflows
* operator-friendly WebUI design

---

## ⚙️ Main Focus Areas

### Android & Network Tooling

I experiment with Android networking, rooted-device workflows, shell-based probing, NAT behavior, proxy routing, and reproducible network reports.

### Proxy Infrastructure

I build and study tools for proxy slot lifecycle management, uplink testing, rotation, rebuild flow, health checks, and operator control panels.

### Operator Dashboards

I like building WebUIs that make technical systems easier to monitor, control, debug, and recover without staring at terminal output like it personally betrayed me.

### AI-Assisted Tools

I also explore AI-assisted workflows for video generation UI, trading research, automation runners, and agent-friendly project documentation.
